# 血管・心臓外科関連 主要学会スケジュール 2026–2030

国内・国際の主要な心臓血管外科関連学会の開催予定（2026〜2030年）をまとめたスケジュール表です。

## 公開ページ
👉 https://nakaji0329.github.io/academic-meetings-2026-2030/

## 機能
- **区分フィルタ**（国内 / 国際 / 地方会 をクリックで表示切替）
- 学会名にカーソルを乗せると**年度横断の開催予定**をポップアップ表示
- 学会名から**公式サイト**へのリンク
- **演題募集締切**（判明分・募集中／締切済を色分け、曜日付き）

## 注意
予定は変更される可能性があります。最新情報は各学会公式サイトでご確認ください。
